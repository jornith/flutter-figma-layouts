# Практическая работа №1. Макеты из Figma на Flutter

Каждый макет сделан в своём приложении Flutter. Весь код экрана находится в `lib/main.dart`.

| Приложение | Макет Figma | Сложность |
|---|---|---|
| `welcome_app` | Welcome | простой |
| `tasks_app` | 01 (задачи) | простой |
| `popular_menu_app` | 21_Light_Popular Menu | сложный |
| `organizer_app` | 43_Light_organizer of event about | сложный |

## Запуск

```
cd welcome_app
flutter pub get
flutter run
```

Так же запускаются остальные приложения. Шрифты подгружаются пакетом `google_fonts`, нужен интернет.
